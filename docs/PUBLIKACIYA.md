# Публикация репозитория

Одна мысль: наружу уходит **болванка** — код и образцы настроек. Всё, что привязано
к конкретной машине и аккаунтам, остаётся на машине.

## Что уходит в репозиторий

| | |
|---|---|
| `app/` | код: цикл, ИИ, хранилище, две админки, разбор источников, тесты |
| `configs/monitor.json` | настройки-образец: источники, слова, порог, расписание |
| `docs/` | скрипт для Google Таблицы и инструкция к нему |
| `vitrina/index.html` | страница проекта, без внешних файлов |
| `.env.example` | только плейсхолдеры: `ВСТАВЬ_ТОКЕН_ОТ_BOTFATHER` и подобные |
| `LICENSE`, `NOTICE` | MIT и происхождение кода |
| `.gitignore` | закрывает секреты и состояние |

## Что остаётся на машине

| Файл | Почему |
|---|---|
| `app/.env` | токен бота, chat id, адрес вебхука, токен Таблицы, ключи модели |
| `app/.env.bak` | его резервная копия — тот же секрет |
| `volume/orders.db` | банк заказов: история прогонов, чужие объявления |
| `exports/leads.csv` | выгрузка лидов |
| `__pycache__/`, `.DS_Store` | мусор |

Все они перечислены в `.gitignore` — не «на честном слове», а правилом.

## Проверка перед первым коммитом

Пять команд, каждая с понятным «здоровым» ответом:

```bash
git status --porcelain                  # пусто — нечего коммитить лишнего
git ls-files | grep -E "\.env$|\.db$|leads\.csv" || echo "секретов и баз нет"
grep -rn "/Users/" $(git ls-files) || echo "личных путей нет"
grep -rnE "bot[0-9]{6,}:|sk-[A-Za-z0-9]{20,}|AIza[0-9A-Za-z_-]{20,}" $(git ls-files) \
  || echo "похожего на токены нет"
python3 app/test_monitor.py             # ИТОГ: ALL_GREEN, код 0
```

Дополнительно, если сомневаешься в одном файле:

```bash
git check-ignore -v app/.env            # должен ответить правилом из .gitignore
```

## Первый push

```bash
git init -b main
git add -A
git commit -m "Радар заказов: сбор с бирж, оценка ИИ, доставка в чат и таблицу"
git remote add origin <адрес репозитория>
git push -u origin main
```

## Если секрет всё-таки уехал

Порядок зависит от того, опубликован репозиторий или нет.

* **Ещё не публиковался** — историю можно переписать: удалить файл из индекса,
  добавить правило в `.gitignore`, пересобрать коммиты.
* **Уже опубликован** — переписывать историю бессмысленно: её уже скачали.
  Меняй сам секрет (перевыпустить токен у BotFather, новый `SHEET_TOKEN` в скрипте
  Таблицы), а потом чисти файл. Смена секрета — единственное, что реально закрывает
  доступ.

## Что этот репозиторий не содержит

Токенов, chat id, адресов вебхуков, путей вида `/Users/...`, локальных баз, выгрузок
и названий чужих проектов. Если что-то из этого появилось в новом коммите —
сработал не тот файл, и проверка выше это покажет.
