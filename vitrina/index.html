Заказы с бирж, отобранные нейросетью —
а не глазами в семь утра

Радар читает семь лент фриланс-бирж, отсеивает мусор по словам, а потом спрашивает модель: «это наша задача или рерайт за пятьсот рублей?» Оценка 0–10, короткое резюме, карточка в Telegram. Всё на стандартной библиотеке Python — ни одной внешней зависимости.

Python 3.9+ 0 ₽ за вызовы модели в локальном режиме MIT 395 автотестов

Пять шагов, каждый проверяем

Порядок не случайный: сначала бесплатный отсев, потом платное внимание модели, и только потом доставка.

  1. СборFL.ru, пять лент Kwork, Freelance.ru. Заказ попадает в банк даже если не прошёл фильтр: «отсеяли» и «не видели» — разные вещи.
  2. СловаКлючевые слова ловятся по началу («бот» поймает «бота», но не «работают»), стоп-слова — только целым словом.
  3. Оценка ИИМодель возвращает JSON: оценка, категория, бюджет, суть, причина. Кривой ответ — не приговор, а повод переспросить один раз.
  4. ДоставкаВ чат уходит только то, что дотянуло до порога. Отметка «отправлено» ставится после ответа Telegram, а не до — иначе упавшая сеть теряет заказ навсегда.
  5. ВитриныCSV перезаписывается каждый цикл, Google Таблица — по желанию: строка уходит в таблицу через вебхук Apps Script с общим токеном.

Что внутри, кроме идеи

Два режима ИИ

Локальный CLI за 0 ₽ или любой OpenAI-совместимый шлюз под ключ компании. Переключается одной строкой в .env, код не правится.

Две админки

Кнопки в Telegram и локальная веб-панель на восьми экранах. Одно ядро, один конфиг: порог и слова не разъезжаются между видами.

Честные отказы

Таймаут, код 401/429, кривой JSON — это статус в базе и повтор, а не тихая пустота. Лимит карточек не обрывает источник.

Без зависимостей

SQLite, urllib, http.server. Нет ни python-telegram-bot, ни streamlit, ни gspread — проверяется тестом.

Тесты, которые умеют падать

395 проверок. В отдельной копии ломали обрезку оценки, срез рассуждений и проверку токена — набор краснел каждый раз.

Секреты отдельно

Токены, ключи и адрес вебхука живут в .env, а рядом лежит .env.example с плейсхолдерами. База и выгрузки закрыты .gitignore.

Запуск

Три команды. Всё остальное — настройка .env под свои ключи.

cd app
cp ../.env.example .env      # токен бота, chat_id, режим ИИ
python3 monitor.py --dry-run # посмотреть, что нашлось, ничего не отправляя
python3 monitor.py           # рабочий цикл: банк, карточки, CSV

python3 test_monitor.py      # 395/395 — ALL_GREEN

Диагностика: крути --dry-run, смотри exports/leads.csv и volume/orders.db. Признак жизни цикла — файл volume/heartbeat.json: он обновляется сам, поэтому «жив или умер» видно снаружи, а не из строки лога, которую печатает сам механизм.

Чего здесь нет и почему

Отправка в Telegram не проверена живьём. В замеренный прогон токен не подключался — поэтому в логе честно «НЕ принял 11 из 11, остаются в очереди». Очередь на повтор — и есть проверка обратного пути.

Режим под чужой ключ проверен на заглушке. 200, 401, 429 и таймаут — на локальном сервере; с настоящим платным ключом не запускался, ключа нет.

Telegram-каналы как источник не используются. Правила платформы запрещают собирать данные для ИИ. Своя карточка через Bot API — можно, чужие каналы — нет.

Тендеры и Хабр Фриланс не подключены. Открытого RSS у них нет: это были бы новые парсеры, а не строка в конфиге. Обещать «добавим галочкой» — врать.

Веб-панель — для своей машины. Слушает 127.0.0.1 и пароля не имеет; наружу её выставлять нельзя.
